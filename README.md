# Ai-Agent
Research Spring AI


# 1.Module Description

## ai-agent-api 
ai agent 对外提供api接口

## ai-agent-core
ai agent 核心模块

## ai-agent-client
ai agent 客户端模块

## ai-agent-dependency
ai agent 依赖管理

## ai-agent-model-starter
